# Normas del proyecto claudio-theme

## Git — cuándo commitear y pushear

**Nunca hacer commit ni push salvo que el usuario lo pida explícitamente.** No commitear "de paso" ni al terminar una tarea.

## Git — qué se commitea

Solo se pushea la carpeta `vanilla-html/`. Todo lo demás (sections/, assets/, templates/, etc.) se ignora hasta nuevo aviso.

## Git — mensajes de commit

Ningún commit puede incluir `Co-Authored-By` ni mención alguna a Claude ni a ningún otro colaborador automático.

## Resolución de problemas

Si un problema no se resuelve al tercer intento, parar y hacer preguntas al usuario para entender mejor qué se está pidiendo antes de seguir intentándolo.
